# ☕ Café & Grãos

## 📌 Sobre o projeto

O *Café & Grãos* é uma aplicação web desenvolvida em equipe como projeto acadêmico do curso de *Análise e Desenvolvimento de Sistemas (ADS)*.

O site simula uma plataforma de cafés especiais, combinando a apresentação de produtos com uma experiência personalizada: o usuário pode responder a um questionário e receber recomendações de cafés disponíveis no próprio catálogo.

O projeto foi concluído com foco em *navegação integrada, interatividade, responsividade e acessibilidade*.

## 🌐 Acesse o projeto

🔗 **https://cafeegraos.vercel.app/HOME/inicial.html**

## 🚀 Funcionalidades

### 🏠 Página inicial e catálogo

- Página inicial com apresentação do projeto e carrossel de imagens.
- Navegação integrada entre as páginas e os principais botões do site.
- Catálogo com *12 produtos de café*, com informações e imagens.
- Página de destaques/painel personalizada após o login, com saudação ao usuário e acesso ao questionário.

### 👤 Acesso e cadastro

- Login demonstrativo com validação dos campos, opção de lembrar usuário e visualização da senha.
- Cadastro com validações em JavaScript, incluindo dados pessoais, contato e confirmação de senha.
- Recuperação de senha simulada, com validações e mensagens de retorno.
- Identificação do usuário durante a navegação e opção de sair da conta (logout).

### ☕ Perfil e recomendações

- Questionário para identificar hábitos e preferências de consumo de café.
- Validação das respostas obrigatórias antes do envio.
- Página de preferências com resumo das respostas do usuário.
- *Recomendação personalizada de dois cafés do catálogo*, de acordo com as respostas do questionário.
- Acesso aos produtos recomendados a partir da página de preferências.
- Possibilidade de refazer o questionário para atualizar as recomendações.

### 🔐 Navegação e controle de acesso

- *Erro 403:* exibido quando o usuário tenta acessar uma área restrita sem estar logado.
- *Erro 404:* página de erro e tratamento do acesso às preferências antes da conclusão do questionário.
- Redirecionamentos entre login, painel, questionário, preferências e produtos, conforme a etapa do usuário.

### ♿ Acessibilidade e experiência

- Layout responsivo, adaptado a diferentes tamanhos de tela.
- Ajuste de tamanho da fonte com controles *A− / A+*.
- Alternância entre tema claro e *modo escuro*, com preferência mantida durante a navegação.
- Feedback visual de validação, mensagens de erro e confirmação nos formulários.

## 🛠️ Tecnologias utilizadas

- *HTML5* — estruturação das páginas.
- *CSS3* — estilização, responsividade e temas visuais.
- *JavaScript* — validações, interatividade, questionário, recomendações e controle de navegação.
- *LocalStorage e SessionStorage* — manutenção de informações demonstrativas no navegador.
- *Git e GitHub* — versionamento e colaboração.
- *Visual Studio Code* — ambiente de desenvolvimento.
- *Vercel* — publicação da aplicação web.

## ℹ️ Como o projeto funciona

A aplicação é executada no *Front-End, sem servidor de autenticação ou banco de dados. Para fins acadêmicos, as ações de login, cadastro e recuperação de senha são **simuladas*, e as informações necessárias ao fluxo são tratadas localmente no navegador.

Isso não impede o uso e a demonstração das funcionalidades previstas para esta versão do projeto.
